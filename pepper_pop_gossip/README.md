# Pepper Pop! — Y2K Gossip Magazine Prototype

A multi-page, responsive website prototype built from scratch with HTML, CSS and JavaScript.

## Pages
- `index.html` — magazine homepage and featured stories
- `gossip.html` — fictional celebrity gossip
- `style.html` — cute at-home fashion tips
- `puppy-quiz.html` — interactive five-question puppy personality quiz
- `about.html` — project information and Harvard-style image references

## Open locally
1. Download and extract the ZIP.
2. Open the `pepper_pop_gossip` folder in a code editor such as Visual Studio Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.

## Publish with GitHub Pages
1. Create a new GitHub repository.
2. Upload the contents of this folder (not the ZIP file itself) to the repository's root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then save.
6. Wait for GitHub Pages to publish the site. Your site URL will appear in the Pages settings.

## Technical checklist
- Five linked HTML pages with consistent navigation and footers.
- External stylesheet: `css/style.css`.
- External JavaScript: `js/script.js`.
- Uses element, class and ID selectors.
- Responsive layouts, semantic landmarks, descriptive image alt text, focus styles and reduced-motion support.
- Interactive puppy quiz with validation, progress indicator, scoring and restart.
- Fictional gossip is clearly labelled as fictional.
- Image references are included on the About page.

## Notes
The web fonts are loaded from Google Fonts and the photographs are embedded from Unsplash's image CDN, so those visual assets require an internet connection. Check the current Unsplash licence and your institution's image-attribution rules before submitting.
